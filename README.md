# Проценка автозапчастей

Клиентское приложение для поиска производителей по артикулу и просмотра предложений с аналогами через сервис Favorit `hsprice`.

## Запуск

```bash
cp .env.example .env
npm install
npm run dev
```

Демо-ключ из документации API уже указан в `.env.example`.

## Проверки

```bash
npm test
npm run build
```

## Стек

React, Redux Toolkit, Axios, Bootstrap 5, Vite. Серверное состояние хранится в Redux, запросы выполняет класс `HsPriceApi`.

Контракт сервиса описан в `docs/openapi.yaml`. Клиент сам разбирает JSON и не опирается на `Content-Type`: бизнес-ошибка может прийти и при HTTP 200 с заголовком `text/plain`.

## Как устроен экран

1. Артикул уходит в поиск через 400 мс после ввода, если в нём хотя бы 3 символа.
2. Список производителей строится из ответа без бренда. В карточке на первой строке бренд и `Арт.: номер`, на второй — наименование, без цены. Список показывает пять карточек, остальные доступны прокруткой. В таблице рядом со счётчиком выбирается, сколько строк видно сразу: 5, 10, 15 или 20. Успешный ответ помнится минуту: повтор в эту минуту берётся из памяти, следующий запрос после минуты снова идёт в сервис и заменяет ответ. Кнопка «Поиск» всегда обновляет список из сети. Ошибки не запоминаются.
3. Выбор производителя запрашивает аналоги (`analogues=on`, `info=on`).
4. Таблица показывает строку на каждый склад: название, производитель, номер, цена и остаток. Название шире остальных равных столбцов. Ширину можно потянуть, но столбец не становится уже своего заголовка. До сортировки сверху идёт выбранная позиция, затем аналоги; внутри группы сначала позиции с остатком. Клик по столбцу сортирует список по возрастанию, затем по убыванию, третий клик возвращает исходный порядок. Длинная выдача рисуется через виртуальный скролл. Запрос к сервису не обрывается клиентским таймаутом.

## Слои

`app` собирает store и страницу. `pages/search` — единственное место с `useDispatch` и `useSelector`. Виджеты и форма получают данные пропсами. Запросы изолированы в `HsPriceApi`, вид строк и сортировка — в `entities/goods`.
